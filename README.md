# 100 Days of Code: C

Completed through **Day 100** using the official [Basic Coding with C question bank](https://maitysoumik.github.io/basic-coding-with-c/questions2.json).

The repository contains 150 standalone C solutions. Days 1 through 50 cover two consecutive questions per day (Q1–Q100); Days 51 through 100 cover one question per day (Q101–Q150). Each solution file begins with its complete question statement and is named with its question number and curriculum category.

Compile any solution with:

```text
gcc -std=c11 -Wall -Wextra -pedantic "path/to/solution.c" -o solution
```
